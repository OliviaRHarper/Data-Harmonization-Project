# Data-Harmonization-Project
Wake Forest CALIBIR research project harmonizing three longitudinal health datasets as part of a greater data sharing effort

Goal: The ultimate goal of this project was to facilitate easier data sharing for longitudinal health datasets by creating a standardized and harmonized data repository. 

Beginning status: The project was in the beginning stages when I was brought in to help. So far relveant variables for three longitudinal health datasets (Health ABC, CHS, and ARIC) had been compiled and an initial variable code document had been created. Initial recoding suggestions had been made for HABC and CHS datasets.
